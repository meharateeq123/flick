# Footage Rules — What to Keep & What to Remove

## 1. No separate logo opener

Do not show the source channel/program logo separately at the start of a scene. Start directly with the actual footage/action — never a logo bumper, intro card, or channel ident before the real content begins.

- **Do this:** start directly with the action (e.g. the podcast hosts already mid-frame, talking).
- **Not this:** a title/logo card ("DOOR BUMPER CLEAR PODCAST") shown before the real footage starts.

## 2. Remove text, logos & graphics from footage

Remove all on-screen text, logos, watermarks, lower thirds, episode titles, show names, and other source graphics baked into the footage before using it. (This extends the on-screen-text rule in `visual-relevancy-rules.md`: not only should we avoid *adding* captions to every line, we should also avoid *keeping* a source clip's own baked-in text/branding.)

- **Do this:** clean footage with no text, logos, lower thirds, or watermarks — just the natural footage.
- **Not this:** footage with a channel logo, episode number ("EPISODE 156"), title ("NASCAR TALK WEEKLY REVIEW"), or topic tags burned into frame.
- When a clean version of the same shot isn't available, prefer cropping/framing around the source graphic (e.g. tighter crop that excludes a corner watermark or lower third) over using the graphic-covered frame as-is.

## 3. Source credit

Do not rely on the source's own branding as attribution. Instead add a small, clean, separate source-credit card — added by the editor/build step, not baked into the footage itself.

Example:
```
Source:
Door Bumper Clear Podcast
(YouTube)
```
Keep it minimal, placed in a clean corner, not overlapping faces or action.

## Important notes

- Never show a separate channel/logo opener.
- Start directly with useful footage.
- Remove unnecessary source text, logos, and graphics whenever technically possible.
- Do not crop out important faces or action to remove a graphic — if removing the graphic would cut off the subject, prefer a different clip/angle instead.
- Keep footage natural, clean, and distraction-free.
- Add source attribution separately as a small, clean credit card — never as part of the footage crop.
