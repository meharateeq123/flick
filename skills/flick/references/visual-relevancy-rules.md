# On-screen text rule

Do not carry a source clip's own baked-in text, captions, subtitles, or lower-thirds into the final video — prefer clean footage without pre-existing on-screen text, and crop/select around a source clip's text overlay when a clean alternative isn't available.

Do not caption every line of narration. Only add an on-screen text element where it's a genuinely important heading/callout (a key fact, a name, a stat, a quote) — the kind of short on-screen text already specified per-beat in the beat sheet. Most scenes should carry no on-screen text at all and let the footage speak for itself.

---

# Strict Scene Relevancy + Visual Continuity + Footage-First Rule

The narration/script is the SINGLE SOURCE OF TRUTH for visual selection.

Every scene MUST directly represent what is being said in that exact part of the narration. RELEVANCY IS MANDATORY.

Do NOT use generic footage just because it belongs to the same broad category.

**Example**
Narration: "One NASCAR driver lost control on the final lap."
- GOOD: actual NASCAR race footage showing a car losing control / spinning; closely related race footage if the exact moment is unavailable.
- BAD: generic racing car driving normally; random car footage; unrelated NASCAR promotional footage.

## Scene 1 = Hook

Scene 1 MUST be a strong VIDEO CLIP. NEVER use a static image for the opening hook unless absolutely unavoidable. The opening visual must immediately communicate the central subject of the video and create curiosity.

For NASCAR: prefer high-speed racing, close racing, overtaking, crash, dramatic finish, pit stop, or another visually powerful moment matching the topic. The first scene must visually explain WHY the viewer should keep watching.

## Every scene must match the script

For every narration segment:
1. Read the exact narration.
2. Identify the specific subject/action/event being discussed.
3. Search specifically for footage representing THAT subject.
4. Do not settle for generic footage if a more relevant clip can be found.
5. Match the visual action to the spoken words.
6. Ensure the visual logically follows the previous scene.
7. Ensure the next scene can naturally continue from the current scene.

Every scene must satisfy: **SCRIPT RELEVANCE + VISUAL RELEVANCE + TEMPORAL RELEVANCE + SCENE-TO-SCENE CONTINUITY.**

## YouTube footage search

When YouTube is an enabled footage source, search broadly across relevant sources rather than relying only on the official NASCAR channel. Search across: NASCAR-related channels, motorsport channels, racing analysis channels, race highlight channels, driver/team channels where permitted, news/sports channels, relevant event coverage, other relevant YouTube sources.

DO NOT restrict footage discovery to the official NASCAR channel. Search using the EXACT subject from the narration, not a generic category term (e.g. not just "NASCAR footage" — use "NASCAR crash", "NASCAR major crash", specific driver + crash, specific race + crash, specific track + crash).

## Clip selection

Choose the MOST RELEVANT available clip, not merely the first result. Rank candidates by: 1) exact subject match, 2) exact event match, 3) exact action match, 4) person/driver match, 5) location/track match, 6) temporal/context match, 7) visual quality, 8) camera quality, 9) continuity with previous scene.

If the exact footage cannot be found, use the closest truthful representation and NEVER use misleading footage. This explicitly rules out simulator/video-game footage (iRacing, NASCAR Heat, sim-racing content generally) standing in for a real event — it must be disqualified outright, not merely down-ranked, even when its title matches the search keywords well.

## Person / player rule

If the narration mentions a specific driver/player/person, the visual MUST show that exact person whenever reasonably possible.
Priority: 1) video of the exact person, 2) authentic image of the exact person, 3) closely related footage only if the person cannot reasonably be shown.
NEVER show a random person while the narration discusses a specific person.

## Image rule

Images are NOT the default. Use images only when: a specific person's authentic image is needed and suitable video cannot be found; a historical person/event has no suitable video; an exact object/document/photo is specifically being discussed; an image provides substantially better factual relevance than video. Otherwise use video.

## Motion graphics rule

Motion graphics are the LAST option. Use them ONLY when they provide necessary information that footage or an image cannot communicate effectively — e.g. date → timeline, exact statistic → counter, comparison → comparison graphic, geography → map, complex data → chart, scientific process → diagram. NEVER use motion graphics merely for decoration or visual variety.

## Scene continuity rule

Every scene MUST logically connect to the previous scene. The video should feel like ONE continuous documentary rather than a collection of unrelated clips. Maintain continuity through: same event, same race, same driver, same location, same vehicle, same time period, same visual context, logical progression of events. Whenever possible, Scene N should naturally lead into Scene N+1.

Good progression example: cars racing at high speed → closer view of the same race → the specific driver making the move → the resulting incident → reaction/aftermath.
Bad (disconnected) example: NASCAR race → random pit stop → random driver interview → random racing crash.

## No generic filler

NEVER use a clip just because it contains a race car, a person, a stadium, NASCAR branding, looks cinematic, fills the timeline, or matches only one keyword. A clip must support the actual sentence being spoken.

If no sufficiently relevant clip exists:
1. Search again using more specific queries.
2. Search alternative relevant sources.
3. Search for the specific driver/event/location.
4. Try an image if appropriate.
5. Use a motion graphic only if informationally necessary.
6. NEVER insert unrelated footage.

## Final relevancy check

Before accepting EVERY scene, ask: "Could a viewer understand why this exact visual is being shown while hearing this exact sentence?" If the answer is NO, reject the clip and search for a better one. Do not proceed until a sufficiently relevant visual is found.

## Final video quality

The final video must feel like: SCRIPT → EXACT VISUAL → NEXT RELATED VISUAL → NEXT RELATED VISUAL → COMPLETE STORY — not SCRIPT → RANDOM FOOTAGE → RANDOM FOOTAGE → RANDOM FOOTAGE.

**Relevance always has higher priority than visual variety, percentage targets, or filling empty timeline space.**
